# Fey SDK

The official TypeScript SDK for interacting with the Fey Factory contract on Base. Fully tested and production-ready.

![npm version](https://img.shields.io/npm/v/@dutchiono/fey-sdk.svg)
![npm downloads](https://img.shields.io/npm/dm/@dutchiono/fey-sdk.svg)

**Links:** [GitHub](https://github.com/dutchiono/fey_sdk) • [npm Package](https://www.npmjs.com/package/@dutchiono/fey-sdk)

## Installation

Install the SDK from npm:

```bash
npm install @dutchiono/fey-sdk ethers
# or
yarn add @dutchiono/fey-sdk ethers
# or
pnpm add @dutchiono/fey-sdk ethers
```

## Quick Start

```typescript
import {
  buildSimpleDeployTokenTx,
  parseTokenCreatedEvent,
  getFeyFactoryContract,
  FEY_FACTORY_ADDRESS,
} from '@dutchiono/fey-sdk';
import { ethers } from 'ethers';

// Setup
const provider = new ethers.JsonRpcProvider('https://mainnet.base.org');
const signer = new ethers.Wallet(PRIVATE_KEY, provider);

// Deploy a token
const tx = buildSimpleDeployTokenTx({
  tokenAdmin: await signer.getAddress(),
  name: 'My Token',
  symbol: 'TKN',
  image: 'ipfs://Qm...',
  metadata: 'ipfs://Qm...',
  context: '',
  originatingChainId: 8453n,
});

const receipt = await (await signer.sendTransaction(tx)).wait();

// Parse events
const event = parseTokenCreatedEvent(receipt);
console.log('Token deployed at:', event?.tokenAddress);
```

## Core Features

### 1. Token Deployment

#### Simple Deployment

For most use cases, use `buildSimpleDeployTokenTx`:

```typescript
import { buildSimpleDeployTokenTx } from '@dutchiono/fey-sdk';

const tx = buildSimpleDeployTokenTx(
  {
    tokenAdmin: '0x...',
    name: 'My Token',
    symbol: 'TKN',
    image: 'ipfs://Qm...',
    metadata: 'ipfs://Qm...',
    context: 'Optional description',
    originatingChainId: 8453n, // Base mainnet
  },
  {
    poolConfig: {
      hook: '0x5B409184204b86f708d3aeBb3cad3F02835f68cC',
      tickSpacing: 60,
    },
    value: ethers.parseEther('1.0'), // ETH for extensions
  }
);
```

### 12. Utilities

#### Address Prediction & Salt Generation

```typescript
import {
  generateSalt,
  generateSaltFromString,
  generateSaltForToken0,
  generateSaltForToken0Simple,
  computeFactorySalt,
  computeCreate2Address,
  predictTokenAddressFromSalt,
  findAddressBelowTarget,
  stringToBytes32,
  FEY_FACTORY_ADDRESS,
  FEY_TOKEN_ADDRESS,
  DEFAULT_TOKEN_INITIAL_SUPPLY,
} from '@dutchiono/fey-sdk';

// Generate salt for deterministic addresses
const salt = generateSalt();
const saltFromString = generateSaltFromString('token-name', 'symbol', 'admin');

// Generate salt that ensures deployed token is token0 (address < FEY address)
// This is automatically used by buildSimpleDeployTokenTx when no salt is provided
const token0Salt = generateSaltForToken0Simple(
  'My Token',
  'TKN',
  '0x...' // tokenAdmin
);

// For precise control, generate salt with CREATE2 address computation
// (requires initCodeHash from token bytecode + constructor args)
const tokenAdmin = '0x...';
const initCodeHash = '0x...'; // keccak256(encoded deploy data with bytecode + args)
const result = await findAddressBelowTarget(
  tokenAdmin,
  initCodeHash,
  FEY_TOKEN_ADDRESS,
  FEY_FACTORY_ADDRESS,
  500_000 // max attempts (matches deployer default)
);
if (result) {
  console.log('Found salt:', result.salt);
  console.log('Predicted address:', result.token);
}

// Predict token address from salt (useful for verifying token0 ordering)
const predictedAddress = predictTokenAddressFromSalt(
  salt,
  tokenAdmin,
  initCodeHash,
  FEY_FACTORY_ADDRESS
);
console.log('Token will be deployed at:', predictedAddress);

// Compute factory salt (used internally)
const factorySalt = computeFactorySalt(tokenAdmin, salt);

// Compute CREATE2 address directly
const create2Address = computeCreate2Address(
  FEY_FACTORY_ADDRESS,
  factorySalt,
  initCodeHash
);
```

**Important:** When deploying tokens with pools (using `buildSimpleDeployTokenTx`), the SDK automatically generates a salt that ensures the deployed token will be token0 (address < FEY address). This is critical for proper pool ordering in Uniswap V4. If you provide your own salt, ensure it will produce a token address less than `0xD09cf0982A32DD6856e12d6BF2F08A822eA5D91D` (FEY token address).

**Using Token Artifacts:** The easiest way to generate salts is using `generateSaltForToken0FromArtifact()` which takes the token artifact (from `feyToken.json` compiled artifact) and automatically computes the `initCodeHash` from the bytecode and constructor arguments. This matches the deployer's exact implementation and ensures compatibility.

#### Tick Calculation for Market Cap

```typescript
import {
  calculateTicksForMarketCap,
  priceToTick,
  tickToPrice,
  roundTickToSpacing,
  DEFAULT_TICK_SPACING,
} from '@dutchiono/fey-sdk';

// IMPORTANT: Tick spacing must ALWAYS be 200 (DEFAULT_TICK_SPACING)
// All ticks must be multiples of 200

// Calculate ticks for 27k USD market cap (target for all token deployments)
// Requires FEY price in USD (fetch from oracle/API)
const feyPriceUSD = 0.50; // Example: $0.50 per FEY
const { tickLower, tickUpper } = calculateTicksForMarketCap(
  feyPriceUSD,
  27_000, // Target market cap: $27,000
  undefined, // Uses DEFAULT_TOKEN_INITIAL_SUPPLY if not provided
  DEFAULT_TICK_SPACING, // Always 200
  40_000 // Tick range width (default: 40000)
);

console.log(`Tick range for 27k market cap: [${tickLower}, ${tickUpper}]`);
// Output: Tick range centered around price for 27k market cap

// Convert between price and ticks
const price = tickToPrice(tickLower);
const tick = priceToTick(price);

// Round tick to spacing (always needed)
const roundedTick = roundTickToSpacing(tick, DEFAULT_TICK_SPACING);
```

**Critical Notes:**
- **Tick spacing is ALWAYS 200** - This is enforced by `DEFAULT_TICK_SPACING`
- **Ticks must be multiples of 200** - Use `roundTickToSpacing()` to ensure compliance
- **27k market cap target** - All tokens should target $27,000 market cap at deployment
- **FEY price required** - You need to fetch FEY price in USD to calculate accurate ticks

## Complete Example

```typescript
import {

  parseTokenCreatedEvent,
  getTokenDeploymentInfo,
  validateDeployPayload,
  FEY_FACTORY_ADDRESS,
} from '@dutchiono/fey-sdk';
import { ethers } from 'ethers';

async function deployToken() {
  // Setup
  const provider = new ethers.JsonRpcProvider('https://mainnet.base.org');
  const signer = new ethers.Wallet(PRIVATE_KEY, provider);

  // Prepare deployment
  const tokenConfig = {
    tokenAdmin: await signer.getAddress(),
    name: 'My Amazing Token',
    symbol: 'MAT',
    image: 'ipfs://QmYourImageHash',
    metadata: 'ipfs://QmYourMetadataHash',
    context: 'A revolutionary token',
    originatingChainId: 8453n,
  };

  // Build transaction
  const tx = buildSimpleDeployTokenTx(tokenConfig, {
    value: ethers.parseEther('1.0'), // 1 ETH for dev buy extension
  });

  // Send transaction
  console.log('Sending deployment transaction...');
  const txResponse = await signer.sendTransaction(tx);
  console.log('Transaction hash:', txResponse.hash);

  // Wait for confirmation
  console.log('Waiting for confirmation...');
  const receipt = await txResponse.wait(2); // Wait for 2 confirmations

  // Parse event
  const event = parseTokenCreatedEvent(receipt);
  if (!event) {
    throw new Error('TokenCreated event not found');
  }

  console.log('✅ Token deployed successfully!');
  console.log('Token Address:', event.tokenAddress);
  console.log('Token Name:', event.tokenName);
  console.log('Token Symbol:', event.tokenSymbol);

  // Get deployment info
  const info = await getTokenDeploymentInfo(provider, event.tokenAddress);
  console.log('Deployment Info:', info);

  // Get token data
  const tokenData = await getTokenData(provider, event.tokenAddress);
  if (tokenData) {
    console.log('Token Data:', {
      name: tokenData.name,
      symbol: tokenData.symbol,
      totalSupply: tokenData.totalSupply.toString(),
      metadata: tokenData.metadata,
    });
  }

  // Get pool information from hook
  if (event.poolId) {
    const poolInfo = await getPoolInfo(provider, event.poolId);
    if (poolInfo) {
      console.log('Pool Info:', {
        feyIsToken0: poolInfo.feyIsToken0,
        locker: poolInfo.locker,
        feyFee: poolInfo.feyFee,
        pairedFee: poolInfo.pairedFee,
      });
    }
  }

  return {
    tokenAddress: event.tokenAddress,
    transactionHash: receipt.hash,
    blockNumber: receipt.blockNumber,
  };
}
```

## Error Handling

```typescript
import { validateDeployPayload } from '@dutchiono/fey-sdk';

try {
  const validation = validateDeployPayload(payload);
  if (!validation.valid) {
    throw new Error(`Validation failed: ${validation.errors.join(', ')}`);
  }

  const tx = buildSimpleDeployTokenTx(payload);
  // ... send transaction
} catch (error) {
  if (error instanceof Error) {
    console.error('Deployment error:', error.message);
  }
}
```

## Best Practices

1. **Always validate payloads** before building transactions
2. **Use `buildSimpleDeployTokenTx`** for most deployments
3. **Parse events** to get the actual token address
4. **Wait for confirmations** before considering deployment complete
5. **Handle errors gracefully** with proper error messages
